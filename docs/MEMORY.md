# Memory System Design

## Overview

Three-layer memory inspired by cognitive science and the Write-Manage-Read paradigm.
The `MemoryManager` orchestrates all three layers and provides a unified interface
to the agent loop.

## Architecture

```
MemoryManager
├── working: WorkingMemory     # Recent conversation turns
├── episodic: EpisodicMemory   # Important events with timestamps
└── semantic: SemanticMemory   # Facts and knowledge
```

## Working Memory

**What it stores:** The last N turns of the agent's conversation (system, user,
assistant, tool messages). This is what gets directly injected into the LLM context.

**Behavior:**
- Turns are appended sequentially
- When total content exceeds `max_tokens` (configurable, default ~8000), the
  oldest turns are replaced by a **summary** generated by the LLM
- The summary is a compressed version: "Earlier: moved to base, fought zombie,
  gathered 32 oak logs, chatted with Player_X about building a house"
- The N most recent turns are always kept at full fidelity

**Implementation:**
```python
class WorkingMemory:
    def __init__(self, max_tokens: int = 8000):
        self.turns: list[dict] = []
        self.summary: str = ""
        self.max_tokens = max_tokens

    def add(self, turn: dict):
        self.turns.append(turn)
        self._maybe_summarize()

    def get_context(self) -> str:
        if self.summary:
            return f"[Summary: {self.summary}]\n" + self._format_recent()
        return self._format_all()

    def _maybe_summarize(self):
        if estimate_tokens(self.turns) > self.max_tokens:
            oldest = self.turns[:-3]  # Keep last 3, summarize rest
            self.summary = llm_summarize(oldest)
            self.turns = self.turns[-3:]
```

## Episodic Memory

**What it stores:** Important events — battles, discoveries, player interactions,
deaths, major accomplishments. Each entry has:
- `event`: description string
- `importance`: float 0.0-1.0 (auto-scored by LLM or heuristic)
- `timestamp`: unix time
- `location`: coordinates (if available)
- `tags`: list of categorical tags (e.g., ["combat", "player_interaction"])

**Behavior:**
- Events are appended with an importance score
- When the store exceeds `max_entries`, low-importance old events are pruned
- `consolidate()` runs periodically to extract patterns → push to semantic memory

**Retrieval:**
- `get_recent(k)` — last k events
- `get_important(threshold)` — events above importance threshold
- `get_by_tag(tag)` — filter by tag

**Implementation:**
```python
class EpisodicMemory:
    def __init__(self, max_entries: int = 200):
        self.events: list[dict] = []
        self.max_entries = max_entries

    def add(self, event: str, importance: float, tags: list[str] = None, location: str = None):
```

## Semantic Memory

**What it stores:** Facts about the world, players, locations, and the agent itself.

**Behavior:**
- Key-value store where keys are natural language labels
- `retrieve(query)` tries keyword match first, falls back to vector search if configured
- Results are ranked by relevance score

**Backends:**
1. **Keyword (default):** Simple TF-IDF or word-overlap matching. Fast, no deps.
2. **Vector (pluggable):** Embedding model → cosine similarity. Requires `embedding_fn`.

The vector backend is configured by passing `embedding_fn` to the constructor:
```python
semantic = SemanticMemory(
    embedding_fn=lambda texts: my_embedding_model.encode(texts)
)
```

**Implementation:**
```python
class SemanticMemory:
    def __init__(self, embedding_fn: callable = None):
        self.facts: dict[str, str] = {}  # key → value
        self.embeddings: dict[str, list[float]] = {}  # key → embedding
        self.embedding_fn = embedding_fn  # optional

    def store(self, key: str, value: str, tags: list[str] = None):
        self.facts[key] = value
        if self.embedding_fn:
            self.embeddings[key] = self.embedding_fn([key])[0]

    def retrieve(self, query: str, top_k: int = 3) -> list[tuple[str, str, float]]:
        # Try keyword first
        results = self._keyword_search(query, top_k)
        if results:
            return results
        # Fall back to vector
        if self.embedding_fn:
            return self._vector_search(query, top_k)
        return []
```

## Persistence

All three memory types serialize to a single JSON file per bot:

```json
{
    "working": {
        "turns": [...],
        "summary": "..."
    },
    "episodic": {
        "events": [
            {"event": "...", "importance": 0.8, "timestamp": 1234567890, ...}
        ]
    },
    "semantic": {
        "facts": {
            "player_base_location": "120 64 -45",
            "player_X likes diamonds": "true"
        },
        "embeddings": {}  // omitted in JSON, rebuilt on load if needed
    }
}
```

## Consolidation Pathway

The "Manage" phase runs periodically:

```
Every N iterations (default: 10):
  1. Scan episodic memory for patterns
     - Same event type occurring 3+ times → extract as semantic fact
     - Repeated player requests → "Player_X often asks about Y"
  2. Prune episodic memory
     - Remove events below importance threshold that are older than 1 hour
  3. Check working memory for summarization trigger
     - If token count > max_tokens, summarize oldest turns
```
